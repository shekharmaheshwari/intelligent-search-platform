Overview

What ISP does, the tech stack, service ports, and the core user flows.

Purpose

ISP is an internal search platform that lets operators connect external data sources — REST APIs, sitemaps, and Google Sheets — and make them full-text and semantically searchable through a single UI. It also writes back to the shared catalog Typesense collection consumed by the PLP (Product Listing Page).

Core User Flows

1. Add a New Source (Create Wizard)

Step 1

Click + in the sidebar. Choose index type: ISP Managed (private isp_{id} collection) or External/Catalog (write-back to a pre-existing Typesense collection). Enter name + description. Saved via POST /v1/indexes.

Step 2

Enter a REST API URL, optional headers, and optional request body.

Step 3

Configure field mapping (source field → target field renames). Submitted via POST /v1/indexes/{id}/ingest/rest — connector config is saved to PostgreSQL and a background task fetches, transforms, embeds, and upserts into Typesense.

Step 4

Progress polling — UI polls GET /v1/indexes/{id}/status until done then shows "View Index".

2. Rebuild a Source

Click ↺ Rebuild on a source. Fields are pre-populated from the saved connector config. Edit if needed, then "Run Rebuild" — calls POST /v1/indexes/{id}/rebuild. The background task re-fetches all data, applies JS extensions in run_order, generates embeddings, drops and recreates the Typesense collection, and upserts all documents.

3. Search (Admin UI)

Type a query and press Enter. ISP calls POST /v1/indexes/{id}/search. If the index has embeddings, the query is embedded and a hybrid search (lexical 0.7 weight + semantic 0.3 weight, merged via Reciprocal Rank Fusion) is performed. Otherwise lexical only. Each result can be expanded to see all fields. An Edit button allows updating popularity and is_featured without re-embedding.

4. Delete a Source

Click ✕ next to a source in the sidebar, confirm the modal, and ISP calls DELETE /v1/indexes/{id}. For managed indexes the isp_{id} Typesense collection is dropped. For external indexes, matching documents are deleted from the external collection. The PostgreSQL row and all status records are also removed.

5. Manage Extensions

Open Extensions in the sidebar footer to manage the global JS transform library. Open Extensions within a source view to assign, reorder, enable/disable, or remove transforms for that specific index. Each extension must export function transform(doc) { ...; return doc; }.
