Connectors

How ISP pulls data from REST APIs, sitemaps, and Google Sheets.

REST Connector rest

The REST connector fetches JSON from any HTTP endpoint and maps fields into ISP's document schema. It is the default connector used by the Create Wizard.

Configuration fields

FieldRequiredDescription
urlYesFull URL of the REST API endpoint to fetch.
methodNoHTTP method. Defaults to GET.
headersNoKey/value pairs added to every request (e.g. Authorization: Bearer ...).
bodyNoJSON body for POST requests.
result_pathNoDot-path into the response to the array of items, e.g. data.results. Leave empty if the root is an array.
field_mapNoObject mapping source field names to target field names in the indexed document.
id_fieldNoSource field to use as the document id. Defaults to id.
title_fieldNoSource field to map to title.
content_fieldNoSource field to map to content (used for embedding).
url_fieldNoSource field to map to the document url.

Example

{
  "url": "https://api.example.com/products",
  "result_path": "data.items",
  "field_map": { "product_name": "title", "body_html": "content" },
  "id_field": "sku",
  "url_field": "canonical_url"
}

Sitemap Connector sitemap

The sitemap connector reads a sitemap XML file, crawls each listed URL, extracts page content using BeautifulSoup, and indexes it. Useful for indexing documentation sites, blogs, or any publicly accessible web content.

Configuration fields

FieldRequiredDescription
sitemap_urlYesURL of the sitemap XML file (supports sitemap index files).
include_patternsNoList of URL substring patterns. Only URLs matching at least one pattern are crawled.
exclude_patternsNoList of URL substring patterns. URLs matching any pattern are skipped, even if they match an include pattern.
user_agentNoCustom User-Agent header sent with every request. Defaults to a generic browser string.
max_pagesNoMaximum number of pages to crawl. Defaults to 500.
content_selectorNoCSS selector for the element(s) whose text becomes the indexed content. Defaults to body.
meta_fieldsNoList of HTML <meta> tag names to extract and store as additional document fields.

Example

{
  "sitemap_url": "https://docs.example.com/sitemap.xml",
  "include_patterns": ["/en/", "/docs/"],
  "exclude_patterns": ["/api/", "/changelog/"],
  "content_selector": "article.main-content",
  "max_pages": 200,
  "meta_fields": ["description", "keywords"]
}

Google Sheets Connector gsheet

The Google Sheets connector reads a spreadsheet and indexes its rows as documents. Each row becomes one document; columns are mapped to ISP fields. Authentication uses a Google service account — no OAuth user flow required.

Auth requirement: The service account JSON key must be set as GOOGLE_SERVICE_ACCOUNT_JSON in backend/.env (single-line JSON, no newlines). The spreadsheet must be shared with the service account email address (the client_email field in the JSON key) with at least Viewer access.

Configuration fields

FieldRequiredDescription
spreadsheet_idYesThe long ID from the Google Sheets URL: docs.google.com/spreadsheets/d/{id}/edit.
sheet_nameNoName of the tab/sheet to read. Defaults to the first sheet.
header_rowNo1-based row number of the header row. Defaults to 1.
id_columnNoColumn name (from header row) to use as the document id. Defaults to id.
title_columnNoColumn name to map to title.
content_columnNoColumn name to map to content (used for embedding).
url_columnNoColumn name to map to the document url.

Service account setup

  1. Go to the Google Cloud Console and create a new service account.
  2. Create a JSON key for the service account and download the .json file.
  3. Collapse the JSON to a single line: jq -c . key.json
  4. Add it to backend/.env: 
    GOOGLE_SERVICE_ACCOUNT_JSON={"type":"service_account","project_id":"...","client_email":"isp@project.iam.gserviceaccount.com",...}
  5. Share your Google Sheet with the client_email address from the JSON, granting Viewer (or higher) permission.

Example

{
  "spreadsheet_id": "1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms",
  "sheet_name": "Products",
  "header_row": 1,
  "id_column": "SKU",
  "title_column": "Product Name",
  "content_column": "Description",
  "url_column": "Page URL"
}
