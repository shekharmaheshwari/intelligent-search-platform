API Reference

Base URL: http://localhost:8001. All endpoints are under /v1/ unless noted. Long-running operations (ingest, rebuild) return HTTP 202 and run as background tasks. Poll GET /v1/indexes/{id}/status for progress.

Index Management

MethodPathDescription
GET /v1/indexes List all indexes. Returns an array of IndexMeta objects.
POST /v1/indexes Create a new managed index. Body: { name, description, is_external?, ... }.
GET /v1/indexes/{id} Get metadata for a single index.
DELETE /v1/indexes/{id} Delete index and its Typesense collection. For external indexes, removes only the matching documents from the external collection.
POST /v1/indexes/discover Scan Typesense for untracked external collections and register them in PostgreSQL.

Ingest & Rebuild

MethodPathDescription
POST /v1/indexes/{id}/ingest/rest Trigger REST ingest (background). Returns 202. Returns 409 if a job is already running.
POST /v1/indexes/{id}/ingest/sitemap Trigger sitemap crawl (background). Returns 202. Returns 409 if already running.
POST /v1/indexes/{id}/ingest/gsheet Trigger Google Sheets ingest (background). Returns 202. Returns 409 if already running.
POST /v1/indexes/{id}/rebuild Full rebuild — drops and recreates the Typesense collection. Background task. Returns 409 if already running.
GET /v1/indexes/{id}/status Poll ingest/rebuild job state. Returns { state, total, indexed, error }. States: idle | queued | running | done | error.

Connectors

MethodPathDescription
POST /v1/indexes/{id}/connectors Add or update a connector config (REST or Sitemap). Saved to the connectors JSONB column.
POST /v1/indexes/{id}/connectors/gsheet Save Google Sheets connector config for the index.

Search

MethodPathDescription
POST /v1/indexes/{id}/search Hybrid / lexical / semantic search. Authenticated. Response includes the raw embedding vectors (vec field). Body: { q, per_page?, page?, search_type? }.
POST /v1/indexes/{id}/search/public Same search — vec excluded from response. Used by external consumers such as the PLP.
GET /v1/catalog/typeahead?q= Live typeahead suggestions across all ISP-managed collections.
GET /v1/catalog/search?q= PLP product search across all ISP collections with editorial boosts (is_featured, popularity). Supports filter_by, page, per_page.
GET /v1/catalog/facets Facet counts by type, tags, and segment.

Documents

MethodPathDescription
GET /v1/indexes/{id}/documents Paginated document listing. Includes vec. Supports page and per_page query params.
GET /v1/indexes/{id}/documents/public Same listing — vec excluded. Safe for external consumers.
PATCH /v1/indexes/{id}/documents/{doc_id} Partial document update. Allowed fields: popularity, is_featured, boost_queries. No re-embedding required.

Extensions

MethodPathDescription
GET /v1/extensions List the global extension library.
POST /v1/extensions Create a new JS extension. Body: { name, description, code }. Code must define function transform(doc) { return doc; }.
PATCH /v1/extensions/{id} Update extension name, description, or code.
DELETE /v1/extensions/{id} Delete an extension from the library. Also unassigns it from all indexes.
GET /v1/indexes/{id}/extensions List extensions assigned to a specific index, ordered by run_order.
PATCH /v1/indexes/{id}/extensions/{ext_id} Assign an extension to an index or update its run_order / enabled flag.
DELETE /v1/indexes/{id}/extensions/{ext_id} Unassign an extension from an index (does not delete from the library).

Settings

MethodPathDescription
GET /v1/settings Get the current embedding model and the list of available models.
PATCH /v1/settings Switch the active embedding model. Applied immediately — no restart required. Caution: switching to a model with a different vector dimension requires a full rebuild of all indexes.

Health

MethodPathDescription
GET /health Liveness probe. Returns { status: "ok" } when the API is running.
