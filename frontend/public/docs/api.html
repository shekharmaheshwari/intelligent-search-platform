API Reference

Base URL: http://localhost:8001. All endpoints are under /v1/ unless noted. Long-running operations (ingest, rebuild) return HTTP 200 with an IngestStatus body and run as background tasks. Poll GET /v1/indexes/{id}/status for progress. Returns 409 if a job is already running.

Index Management

MethodPathDescription
GET /v1/indexes List all indexes. Returns an array of IndexMeta objects.
POST /v1/indexes Create a new managed index. Body: { name, description, is_external?, ... }.
GET /v1/indexes/{id} Get metadata for a single index.
DELETE /v1/indexes/{id} Delete index and its Typesense collection. For external indexes, removes only the matching documents from the external collection.
POST /v1/indexes/discover Scan Typesense for untracked external collections and register them in PostgreSQL.

Ingest & Rebuild

MethodPathDescription
POST /v1/indexes/{id}/ingest/rest Trigger REST ingest (background). Returns 200 + IngestStatus. Returns 409 if a job is already running.
POST /v1/indexes/{id}/ingest/sitemap Trigger sitemap crawl (background). Returns 200 + IngestStatus. Returns 409 if already running.
POST /v1/indexes/{id}/ingest/gsheet Trigger Google Sheets ingest (background). Returns 200 + IngestStatus. Returns 409 if already running.
POST /v1/indexes/{id}/rebuild Full rebuild — drops and recreates the Typesense collection, then re-indexes all documents. Returns 200 + IngestStatus. Returns 409 if already running.
GET /v1/indexes/{id}/status Poll ingest/rebuild job state. Returns { state, total, indexed, error }. States: idle | queued | running | done | error.

Connectors

MethodPathDescription
POST /v1/indexes/{id}/connectors/rest Save REST connector config for the index (URL, headers, body, field mapping). Stored in PostgreSQL; call /ingest/rest to start fetch.
POST /v1/indexes/{id}/connectors/sitemap Save sitemap connector config (sitemap URL, include/exclude patterns, user agent). Call /ingest/sitemap to start crawl.
POST /v1/indexes/{id}/connectors/gsheet Save Google Sheets connector config (spreadsheet ID, sheet name, field mapping). Call /ingest/gsheet to start import.

Search

MethodPathDescription
POST /v1/indexes/{id}/search Hybrid / lexical / semantic search. Authenticated. Response includes the raw embedding vectors (vec field). Body: { q, per_page?, page?, search_type? }.
POST /v1/indexes/{id}/search/public Same search — vec excluded from response. Used by external consumers such as the PLP.
POST /v1/catalog PLP product search across all ISP-managed collections. Body: { q, type, search_mode, page, per_page, filters?, action_history? } — filters is a generic Record<string, string[]> keyed by any facetable field. Returns { items, total, page, total_pages, context_actions_used }.
GET /v1/catalog/facets?type= Aggregate facet counts for the PLP filter sidebar. Returns whatever fields are marked facet: true in the Typesense schema — not hardcoded to any specific field names. Scans up to 250 docs per collection.
GET /v1/suggest?q=&limit= Typeahead autocomplete across all ISP-managed collections. Minimum 2 chars. Returns up to limit (default 8) suggestions with { text, type }.
GET /v1/intent/tab?q= Classify a search query into a tab label (e.g. device vs accessory) using vector similarity against indexed collections with intent_label set.
GET /v1/indexes/{id}/facets Facet counts for a single ISP-managed index, read directly from Typesense. Returns all fields with facet: true in the schema — no field names hardcoded. Enable faceting for any field via the Fields tab in the ISP console. Public — no auth required.

Documents

MethodPathDescription
GET /v1/indexes/{id}/documents Paginated document listing. Includes vec. Supports page and per_page query params.
GET /v1/indexes/{id}/documents/public Same listing — vec excluded. Safe for external consumers.
PATCH /v1/indexes/{id}/documents/{doc_id} Partial document update. Allowed fields: popularity, is_featured, boost_queries. No re-embedding required.

Extensions

MethodPathDescription
GET /v1/extensions List the global extension library.
POST /v1/extensions Create a new JS extension. Body: { name, description, code }. Code must define function transform(doc) { return doc; }.
PUT /v1/extensions/{id} Update extension name, description, or code.
DELETE /v1/extensions/{id} Delete an extension from the library. Also unassigns it from all indexes.
GET /v1/indexes/{id}/extensions List extensions assigned to a specific index, ordered by run_order.
POST /v1/indexes/{id}/extensions/{ext_id} Assign an extension to an index or update its run_order / enabled flag.
DELETE /v1/indexes/{id}/extensions/{ext_id} Unassign an extension from an index (does not delete from the library).

Settings

MethodPathDescription
GET /v1/settings Get the current embedding model and the list of available models.
PUT /v1/settings Switch the active embedding model. Applied immediately — no restart required. Caution: switching to a model with a different vector dimension requires a full rebuild of all indexes.
PUT /v1/settings/customer-context Enable/disable the customer context master flag and individual sub-flags (vector_blending_enabled, affinity_boost_enabled, viewed_penalty_enabled). Cached in memory; no DB read on hot search path.
PUT /v1/settings/rexbert-config Set the shared RexBERT endpoint URL and optional API key for all RexBERT model variants.

Health

MethodPathDescription
GET /health Liveness probe. Returns { status: "ok" } when the API is running.
