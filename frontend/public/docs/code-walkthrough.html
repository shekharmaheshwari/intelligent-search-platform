Startup sequence (main.py)

main.py is the FastAPI entry point. On every container start, the lifespan handler runs these steps before the first request is served:

1. bootstrap_secrets() fetch secrets from Vault / AWS / env → inject into os.environ 2. job_lock.release_stale() clear any Redis locks left by a prior container crash 3. init_db() CREATE TABLE IF NOT EXISTS all PostgreSQL tables 4. seed_slugs() back-fill human-readable slugs for indexes created pre-slug 5. load_embed_model() restore operator-chosen embedding model from app_settings 6. _ensure_catalog_collection() create shared Typesense catalog collection if missing 7. ts.migrate_isp_fields() add new schema fields to existing isp_* collections 8. _seed_extensions_from_files() scan backend/extensions/*.js → upsert into DB → auto-assign

After lifespan: CORS middleware → optional AuthMiddleware (if AUTH_ENABLED=true) → all routers mounted at /v1.

database.py

backend/src/isp/services/infra/database.py asyncpg connection pool and schema initialisation
get_pool() → asyncpg.Pool
Lazy singleton — creates the asyncpg connection pool (min 2, max 10) on first call and reuses it for the process lifetime. Reads DATABASE_URL from config.
init_db() → None
Creates all PostgreSQL tables using CREATE TABLE IF NOT EXISTS — safe to call on every startup. Also runs idempotent ALTER TABLE … ADD COLUMN IF NOT EXISTS statements for columns added after initial schema, and backfills intent_label for the four known ISP indexes.

typesense_client.py

backend/src/isp/services/infra/typesense_client.py Thin wrapper around the Typesense SDK — all Typesense I/O goes through this module
get_client() → typesense.Client
Lazy singleton Typesense client. Connects to typesense_host:typesense_port from config with a 10 s connection timeout.
collection_name(index_id) → str
Returns isp_{index_id} — the naming convention for ISP-managed Typesense collections.
create_collection(index_id, vec_dim?) → None
Provisions a new ISP-managed collection with a structural base schema: title, content, url, source_type, indexed_at, metadata, popularity, is_featured, version_score, boost_queries_equal, boost_queries_contains, vec (float[]), and a .* auto wildcard. No domain-specific fields (category, manufacturer, etc.) are hardcoded — they are indexed automatically from extension/connector output via the wildcard and made facetable via the Fields tab. Idempotent — does nothing if collection already exists.
drop_collection(index_id) → None
Deletes an ISP-managed collection. Silently ignores missing collections.
migrate_isp_fields() → None
Idempotent startup migration — adds version_score, boost_queries_equal, boost_queries_contains to any isp_* or catalog collection that doesn't already have them. Previously also added category and manufacturer — these are no longer hardcoded and instead come from extension output via the .* wildcard. Errors are swallowed — a missing field means the feature is inactive until next rebuild.
upsert_documents(index_id, docs) → int
Batch-upsert documents into an ISP-managed collection. Returns count of successful upserts. Logs detailed error info on failures.
search_documents(index_id, q, mode, page, per_page, exclude_vec?) → dict
Single-pass lexical or semantic search on an ISP-managed collection. Used as the fallback path when no embedding vector is available. Sorts by is_featured:desc, _text_match:desc.
search_with_vec(index_id, q, vec, page, per_page, version_boost?, exclude_vec?) → dict
Hybrid search via multi_search (2 passes) + Reciprocal Rank Fusion. Fetches per_page × 3 candidates from both lexical (weight 0.7) and semantic (weight 0.3) passes, merges with RRF (K=60), then applies editorial boosts for is_featured, popularity, boost_queries_equal, and boost_queries_contains before slicing the requested page.
search_external(col, q, filter_by, query_by, vec?, page, per_page) → dict
Same hybrid RRF logic applied to an external (non-ISP) Typesense collection. filter_by is applied to both passes to preserve source isolation (e.g. type:=device). Falls back to single lexical pass when no vector is supplied.
list_documents(index_id, page, per_page, exclude_vec?) → dict
Paginated document listing sorted by indexed_at:desc.
update_document_fields(col_name, doc_id, fields) → bool
Partial field update using Typesense action=update — only overwrites supplied keys, leaves the rest intact.
retrieve_document(col_name, doc_id) → dict | None
Fetches a single document by id. Returns None if not found.
delete_from_collection(col_name, filter_by) → int
Deletes all documents matching a filter expression from any named collection.
upsert_to_collection(col_name, docs) → int
Upserts into any named collection — used for catalog write-back from external sources.
count_documents(index_id) / count_external(col, filter_by) → int
Returns document count for ISP-managed or external collections respectively. Returns 0 on error.
set_vec_dim(dim) / get_vec_dim() → None / int
Get/set the vector dimension used when provisioning new collections. Updated at runtime when the operator switches embedding models.

embedding_service.py

backend/src/isp/services/infra/embedding_service.py Multi-provider embedding with a two-tier cache (L1 LRU + L2 Redis)

Supported providers: Voyage AI (voyage-3, voyage-3-large, …), OpenAI (text-embedding-3-small), RexBERT (rexbert-micro/mini/base/large), Custom (any OpenAI-compatible endpoint). Cache: L1 LRUCache (2048 slots, in-process) → L2 Redis (24 h TTL). Vectors stored as struct.pack bytes (~4 KB per 1024-dim vector).

embed_texts(texts, model?) → list[list[float]]
Embed a list of document strings using input_type="document" (Voyage AI optimised for indexing). Used during ingest. Returns empty list when the provider API key is not configured.
embed_query(q, model?) → list[float]
Embed a single search query using input_type="query" (Voyage AI optimised for retrieval). Checks L1 LRU → L2 Redis before calling the provider API. Writes back to both cache layers on a miss. Returns empty list on failure.
get_current_model() / set_current_model(model) → str / None
Get or set the active embedding model name at runtime. Calls ts.set_vec_dim() when switching to a model with a different output dimension.
set_openai_api_key(key) / set_custom_config(endpoint, model, dim, key)
Runtime updates for OpenAI and custom provider configuration without restarting the process.

extension_runner.py

backend/src/isp/services/infra/extension_runner.py V8 JavaScript sandbox via PyMiniRacer — transforms documents before indexing

Each extension is compiled into its own V8 isolate once per ingest batch, then called for every document. No filesystem, no network, no Node.js APIs — ECMAScript built-ins only. Synchronous V8 execution is wrapped in run_in_executor so it does not block the asyncio event loop.

apply_extensions(docs, extension_records) → list[dict] [async]
Async entry point. Delegates to _run_sync in a thread executor. Calls each enabled extension's transform(doc) function in ascending run_order. Compile failures skip the extension for the entire batch; runtime errors on a single document keep that document in its pre-error state — neither abort the ingest.
filter_urls(urls, extension_records) → list[str] [async]
Async entry point for URL pre-filtering during sitemap crawl. Calls each extension's optional filterUrl(url) function. A falsy return drops the URL before any HTTP fetch occurs. Extensions that don't define filterUrl are silently skipped.
_run_sync(docs, extension_records) → list[dict]
Synchronous V8 execution loop. Compiles each extension once into a MiniRacer isolate, then iterates all documents, applying the extension chain in order.
_filter_urls_sync(urls, extension_records) → list[str]
Synchronous URL filter loop. Checks typeof filterUrl === "function" before calling to skip extensions that only define transform.

job_lock.py

backend/src/isp/services/infra/job_lock.py Redis-backed distributed lock — prevents concurrent rebuilds on the same index

Key: isp:job:{idx_id}. Value: {hostname}:{uuid4()}. Initial TTL: 10 min. Heartbeat extends TTL every 5 min. Lua scripts for atomic compare-and-delete / compare-and-extend prevent one instance from releasing another's lock. Degrades gracefully when Redis is unreachable — single-instance deployments are unaffected.

acquire(idx_id) → str | None [async]
Try to set isp:job:{idx_id} with NX (only if not exists). Returns an opaque token string on success, or None if another instance already holds the lock.
release(idx_id, token) → None [async]
Atomically delete the lock key only if the stored value matches token (Lua compare-and-delete). Prevents instance A from releasing a lock re-acquired by instance B after A's TTL expired.
heartbeat(idx_id, token) → None [async]
Runs as an asyncio task alongside the background rebuild job. Extends the lock TTL every 5 minutes (Lua compare-and-extend) until the task is cancelled in the finally block.
release_stale_for_instance() → None [async]
Called once at startup. Scans isp:job:* and deletes any lock whose value starts with the current container hostname — cleaning up orphaned locks from a prior crash.

secrets.py

backend/src/isp/services/infra/secrets.py Provider-based secret abstraction — env / Vault / AWS Secrets Manager
bootstrap_secrets() → None
Called before any ISP module imports config.py. Fetches all _SECRET_KEYS from the active provider and injects them into os.environ. Skips keys already present. No-op when SECRET_PROVIDER=env (default). Controlled by the SECRET_PROVIDER env var: env | vault | aws.
get_secret(key) → str
Fetch one secret from the configured provider. Vault: reads from KV v2 mount isp/ via hvac. AWS: calls secretsmanager.get_secret_value(SecretId=f"isp/{key}") via boto3 (credentials from IAM Role on EC2 — nothing on disk). Returns empty string on error.

index_service.py

backend/src/isp/services/domain/index_service.py PostgreSQL CRUD for indexes, ingest_status, and deleted_splits tables
list_indexes() → list[IndexMeta]
Returns all indexes ordered by created_at DESC.
get_index(idx_id) → IndexMeta | None
Fetch a single index by hex id. Returns None if not found.

Fetch a single index by human-readable slug. Used by _resolve_index in routers so consumer-facing URLs can use /phones instead of /isp_abc123.

Inserts a new row with a 12-char hex id. Auto-generates a URL-safe slug from the name (_slugify) and ensures uniqueness by appending the first 4 chars of the id on collision. The Typesense collection is provisioned separately in the router.

Deletes the DB row. The router is responsible for dropping the Typesense collection.

Read and write the ingest_status table. State machine: idle → running → ready | error. The rebuild handler polls this to stream progress to the UI.

Back-fill empty slug columns for indexes created before the slug column was added. Called once at startup after init_db.
discover_external_collections() → list[IndexMeta]
Scans all Typesense collections and registers any that are not yet tracked in PostgreSQL as external ISP sources. Uses _KNOWN_SPLITS to map collection names to named sub-sources (e.g. catalog → [devices, accessories, …]).
_slugify(name) → str
Lowercase → spaces/underscores to hyphens → strip non-alphanumeric → collapse hyphens → strip leading/trailing hyphens.

jwt_utils.py

backend/src/isp/auth/jwt_utils.py HS256 JWT sign / verify for ISP admin sessions
create_token(email, name) → str
Signs an HS256 JWT with payload {sub: email, name, iat, exp}. TTL defaults to 8 hours (JWT_TTL_MINUTES). Called after a successful OAuth2 callback.
verify_token(token) → dict
Decodes and validates the JWT signature and expiry. Raises jwt.PyJWTError on failure — caught by the middleware to return 401.

provider.py

backend/src/isp/auth/provider.py OAuth2 adapters for Google, GitHub, and Microsoft
_cfg() → dict
Returns the auth/token/userinfo URLs and scope for the configured OAUTH_PROVIDER. Microsoft URLs are built dynamically from OAUTH_TENANT_ID (common by default).
get_authorization_url(state) → str
Builds the provider's consent screen URL with CSRF state, client id, redirect uri, and scope. Adds prompt=select_account for Google and Microsoft; access_type=online for Google only.
exchange_code(code) → str [async]
Posts the authorization code to the provider's token endpoint (with client secret) and returns the access_token string.
get_userinfo(access_token) → dict [async]
Fetches {email, name} from the provider's userinfo endpoint. GitHub: falls back to GET /user/emails if primary email is hidden. Microsoft: maps displayName + mail (or userPrincipalName). Google: maps OIDC standard claims.

middleware.py

backend/src/isp/auth/middleware.py Starlette BaseHTTPMiddleware — registered only when AUTH_ENABLED=true
AuthMiddleware.dispatch(request, call_next) [async]
Evaluates every request in this priority order:
  1. OPTIONS → always pass through (CORS preflight)
  2. /health, /auth/*, /docs, /openapi.json, /redoc → always open
  3. /v1/catalog/*, /v1/analytics/*, /v1/intent/* → open (PLP-facing)
  4. /v1/indexes/{id}/search/public → open
  5. All other /v1/* → extract Bearer token → verify_token() → 401 on failure
  6. Everything else → pass through
_extract_token(request) → str | None
Reads token from Authorization: Bearer header first, then falls back to isp-auth-token cookie.

routers/auth.py

backend/src/isp/routers/auth.py OAuth2 login / callback / logout / me — always registered, always public
GET /auth/login
Generates a 16-byte hex CSRF state token, sets it as an httpOnly oauth_state cookie, and redirects the browser to the provider's consent screen.
GET /auth/callback?code=&state=
Verifies the state cookie matches the query param (CSRF check). Exchanges the code for an access token, fetches {email, name}, optionally enforces OAUTH_ALLOWED_DOMAIN, issues an HS256 JWT, and redirects to {OAUTH_FRONTEND_URL}?isp_token=<jwt>.
POST /auth/logout
Clears the isp-auth-token cookie and returns 200. The frontend also clears localStorage on its side.
GET /auth/me
Extracts the Bearer token from the request, verifies it, and returns {email, name} from the JWT payload.

frontend — api.ts

frontend/src/lib/api.ts Single typed HTTP client — all backend calls go through this file
req<T>(path, opts?) → Promise<T>
Core fetch wrapper. Sets Content-Type: application/json. When PUBLIC_AUTH_ENABLED=true: reads JWT from localStorage('isp-auth-token') and attaches as Authorization: Bearer. On 401: clears token and redirects to /auth/login. On non-2xx: throws Error with status + body text. BASE is set at build time via PUBLIC_API_URL.

The api object exports typed methods: listIndexes, createIndex, deleteIndex, rebuildIndex, getStatus, listDocuments, search, listExtensions, assignExtension, updateIndexExtension, getSettings, saveSettings, logImpression, logClick, and more.

Ingest / Rebuild flow

POST /v1/indexes/{id}/rebuild (with connector config) │ ├─ Persist connector config to DB (router) ├─ Acquire Redis job lock (job_lock.acquire) │ └─ None → 409 Conflict (another rebuild running) ├─ ingest_status → running │ ├─ Connector.fetch_documents() │ ├─ rest_connector → HTTP GET/POST + JSONPath extraction + pagination │ ├─ sitemap_connector → parse XML → filter_urls() → HTTP fetch each page │ └─ gsheet_connector → Sheets API v4 rows │ ├─ _inject_isp_type(docs) infer catalog type from connector body ├─ apply_extensions(docs) V8 sandbox: transform(doc) per extension in run_order │ ├─ _resolve_doc_id(raw_id, fallback) │ ├─ extension ID is alphanumeric/hyphen/underscore → use as-is (e.g. SKU, familyCode) │ └─ integer or special chars → hash to 16-char hex (stable, Typesense-safe) │ ├─ _generic_catalog_mapper / _ensure_isp_schema │ └─ all extension fields pass through via .* wildcard; no domain fields hardcoded │ ├─ embedding_service.embed_texts(titles) │ └─ Provider API (Voyage / OpenAI / RexBERT / custom) → list[list[float]] │ ├─ ts.upsert_documents(index_id, docs) OR ts.upsert_to_collection("catalog", docs) │ ├─ re-apply field_config (facet/searchable settings persist across rebuilds) ├─ ingest_status → ready (or error) └─ job_lock.release()

Search flow

POST /v1/indexes/{id}/search { q, mode, page, per_page } │ ├─ _resolve_index(id_or_slug) │ └─ try slug → try hex id → 404 │ ├─ embedding_service.embed_query(q) │ ├─ L1 LRUCache hit → return cached vector │ ├─ L2 Redis hit → deserialise struct.pack bytes → write L1 → return │ └─ Provider API → write L2 (bytes) + L1 → return │ ├─ IS EXTERNAL INDEX? │ ├─ Yes → ts.search_external(col, q, filter_by, query_by, vec, …) │ │ └─ multi_search: lexical + semantic → RRF merge (K=60, 0.7/0.3) │ │ → scoped to external_filter (e.g. type:=device) │ │ │ └─ No → ts.search_with_vec(index_id, q, vec, …) │ └─ multi_search: lexical + semantic → RRF merge │ + editorial boosts (is_featured, popularity, boost_queries_*) │ + optional version_score boost │ └─ Response { hits, found, page }
